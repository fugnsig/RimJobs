# Screenshots

The main `README.md` references the image files below. Drop PNGs with these exact
names into this folder, then commit. Until they exist, the README will show broken
image icons, so add them before pushing (or temporarily comment out the gallery).

Order matters: the first two tell the round-trip story (import a real save, then edit it
and write it back), which is the thing nothing else does. Lead with those.

| Filename | What to capture | Suggested size |

## Tips

- Use the **window mode** (not the tiny widget) so panels are legible.
- Keep a consistent theme across all shots (all dark or all light).
- Crop out empty space so the content fills the frame.
- PNG keeps text crisp. Capture at 2x where you can, the README scales them down.
- The gallery images are shown at 400px wide each; anything from 600 to 900px wide
  source looks sharp.

## Social preview card

GitHub also shows a "social preview" image when the repo link is shared (Discord,
Twitter, etc.). That one is set in the repo settings, not here. Recommended size is
**1280 x 640**. The `hero.png` (or a branded variant of it) works well.
